Linux 后台任务通过 tmux 运行，并在 SSH 或本地前端断开期间自动续接原 Codex 聊天。

本版本提供：

- 任务开始前建立原 app-server 的持久订阅；线程被卸载时在原服务器重新加载。
- 核验线程、工作目录、模型、审批及权限配置；配置变化或 writer 冲突时保留结果并停止派发。
- 分别保存计算结果与续接状态，用精确 turn ID 和完成事件确认续接，不盲目重跑任务或重发请求。
- 保留可查看的 tmux 会话，提供 `doctor`、`status` 和 `recover` 命令。

安装：下载 `background-job-continuation-2.1.0.zip`，解压后将 `background-job-continuation` 文件夹放入 `${CODEX_HOME:-$HOME/.codex}/skills/`。已有同名 skill 时先备份。ZIP 包含 skill、Python helper、协议说明和 MIT 许可证。

验证：19 项隔离测试通过；真实 app-server 前端断开与线程卸载测试通过；物理 SSH 测试中，任务和续接均在用户报告的 08:56–09:34 断线区间内完成。详情见 [公开测试报告](https://github.com/VictoriqueDeBlois/background-skill/blob/v2.1.0/test-report.json)。

环境：Linux、Python 3.10+、tmux 和支持 `app-server proxy` 的共享 Codex app-server。已验证 Codex 0.159.3 / tmux 3.4。原服务器必须持续运行并能访问模型服务；人工审批或客户端专属工具可能等待重连。

附件 `SHA256SUMS` 可用于核对 ZIP 完整性。项目采用 MIT 许可证。
